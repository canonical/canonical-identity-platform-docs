Charmed Authentik
=================

Charmed Authentik is a unified identity provider (IdP) and directory gateway
uniting OpenID Connect (OIDC) and LDAP protocol support in one control plane.
It serves modern OIDC applications and legacy LDAP-oriented consumers from a
single deployment, with a built-in administrative console.
