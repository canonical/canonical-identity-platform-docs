Charmed Authentik LDAP Outpost K8s
==================================

.. meta::
   :description: Technical reference for the Charmed Authentik LDAP Outpost Kubernetes operator.

``authentik-ldap-outpost`` is a Kubernetes charmed operator for the LDAP Outpost component of `Authentik <https://goauthentik.io/>`_, an open-source Identity Provider (IdP).

The ``authentik-ldap-outpost`` operator exposes an LDAP and LDAPS interface to existing directory-aware legacy systems (such as SSSD and PAM), translating LDAP search and bind requests into Authentik policy evaluation and authentication flows on top of `Juju <https://juju.is/>`_.
