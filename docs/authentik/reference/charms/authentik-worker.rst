Charmed Authentik Worker K8s
============================

.. meta::
   :description: Technical reference for the Charmed Authentik Worker Kubernetes operator.

``authentik-worker`` is a Kubernetes charmed operator for `Authentik <https://goauthentik.io/>`_, an open-source Identity Provider (IdP) that unifies identity management, authentication, and authorization.

The ``authentik-worker`` operator handles background task execution, asynchronous event queues, user synchronization, policy pre-computation, and email dispatch on top of `Juju <https://juju.is/>`_.
