Charmed Authentik Server K8s
============================

.. meta::
   :description: Technical reference for the Charmed Authentik Server Kubernetes operator.

``authentik-server`` is a Kubernetes charmed operator for `Authentik <https://goauthentik.io/>`_, an open-source Identity Provider (IdP) that unifies identity management, authentication, and authorization.

The ``authentik-server`` operator manages the core web interface, REST API, authentication engine, and database migration lifecycle of Authentik on top of `Juju <https://juju.is/>`_.
