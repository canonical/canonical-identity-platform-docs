Canonical Identity documentation
================================

Canonical Identity is a suite of identity and access management (IAM) solutions
provided by Canonical. It is designed to be a highly modular, secure, and scalable
ecosystem that provides centralized authentication, authorization, and access
governance controls across diverse infrastructures.
