Canonical Identity Platform
===========================

The Canonical Identity Platform is an Ory-based identity and access management (IAM)
stack engineered for high-scale OpenID Connect (OIDC) and OAuth 2.0 workloads.
Built on Kratos and Hydra, it provides centralized authentication, authorization,
and access governance for cloud-native environments.
